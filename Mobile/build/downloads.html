사용자 앱

학생 인증서를 관리하고 구매한 티켓의 QR을 표시합니다.

사용자 APK 다운로드 (v5)

관리자 앱

휴대폰 카메라로 티켓 QR을 스캔하고 입장을 처리합니다.

관리자 APK 다운로드 (v3)

설치 순서

  1. 휴대폰에서 필요한 APK를 다운로드하고 파일을 엽니다.
  2. 설치 권한 안내가 나오면 해당 브라우저 또는 파일 앱의 설치를 허용합니다.
  3. 앱을 실행하고 로그인합니다. QR을 스캔할 때 카메라 권한을 허용해주세요.

기존 TicketPro 시연 앱이 있다면 삭제하지 않고 업데이트 설치해주세요. Expo Go에서 사용하던 계정은 처음 한 번 로그인하거나 모바일 연결이 필요합니다.
